# Student Manager

Full-stack student management application.

this is just an exercice

## Structure

- `backend/` — Express + TypeScript REST API
- `frontend/` — React + TypeScript dashboard

Each project has its own dependencies and must be run independently.

## Quick Start

\`\`\`bash
# Terminal 1
cd backend
npm install
npm run dev

# Terminal 2
cd frontend
npm install
npm run dev
\`\`\`

See each folder's own setup instructions for environment variables.

you need database too
